# Contenido de Instagram · @medlogic.ai

7 posts, 7 historias y 3 reels hechos con [Remotion](https://www.remotion.dev). Todo está pensado para que la gente **comente, vote, comparta y entre a la web**, no solo para que lo vea pasar.

Los archivos listos para subir están en `out/`:

| Carpeta | Formato | Medidas |
| --- | --- | --- |
| `out/posts/` | PNG | 1080 × 1350 (4:5, el que más ocupa en el feed) |
| `out/historias/` | MP4, 6–8 s | 1080 × 1920 |
| `out/reels/` | MP4, 23–26 s | 1080 × 1920 |

Los videos van **sin música a propósito**: al subirlos, ponle un audio en tendencia desde la biblioteca de Instagram. Eso ayuda mucho al alcance.

## Editar y volver a renderizar

Requiere Node.js 22.

```bash
cd instagram
npm install
npm run studio          # vista previa en el navegador para editar textos y animaciones
npm run render          # vuelve a generar todo en out/
npm run render -- reel-2   # solo lo que contenga «reel-2» en el nombre
```

- Textos de cada pieza: `src/posts/Posts.tsx`, `src/stories/Stories.tsx`, `src/reels/Reels.tsx`.
- Preguntas de los quiz: `src/data.ts` (copiadas del banco de la app).
- Días que faltan: cambia `PUBLISH_DATE` en `src/theme.ts` a la fecha en que vayas a publicar y vuelve a renderizar. Si cambias la fecha, actualiza también el «126 días» de los pies de foto.
